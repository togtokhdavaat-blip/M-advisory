# M ADVISORY: Production-д гаргах заавар

Энэ заавар нь платформыг жинхэнэ хэрэглэгчдэд нээхийн тулд **зөвхөн та өөрөө** хийх ёстой алхмуудыг дарааллаар нь бичсэн. Код, тест, CI бүгд бэлэн. Доорх алхмууд нь танай байгууллагын нэр дээр бүртгэл үүсгэх, нууц түлхүүр оруулах, хуулийн текст батлах зэрэг зөвхөн эзэмшигч хийх боломжтой ажлууд юм.

Нийт хугацаа: QPay гэрээ байгаа бол ойролцоогоор 1–2 цаг. QPay гэрээ шинээр хийх бол QPay-ийн хариунаас хамаарна.

---

## 0. GitHub repo-г хувийн (private) болгох

1. https://github.com/togtokhdavaat-blip/m-advisory → **Settings** → доош гүйлгээд **Danger Zone** → **Change visibility** → **Make private**.
2. Код олон нийтэд нээлттэй байх ёсгүй. Нууц түлхүүр repo-д байхгүй ч бизнесийн логик, үнийн бүтэц харагдана.

---

## 1. Supabase (өгөгдлийн сан, нэвтрэлт, файл хадгалалт)

1. https://supabase.com дээр бүртгүүлээд **New project** дарна.
   - Name: `m-advisory`
   - Database password: урт санамсаргүй нууц үг үүсгээд **нууц газар хадгална** (дараа нь хэрэгтэй).
   - Region: **Northeast Asia (Tokyo)**. Монголд хамгийн ойр.
   - Plan: эхлээд Free хангалттай. Жинхэнэ үйлчлүүлэгч орж эхлэхэд **Pro** (сард ~$25) болгоно. Pro нь өдөр бүрийн нөөц хуулбар (backup) хийдэг.
2. **SQL Editor** → **New query** нээгээд repo-ийн `supabase/migrations/` хавтас дахь файлуудыг **нэрийн дарааллаар нь нэг нэгээр** хуулж буулгаад **Run** дарна:
   1. `20261101000100_core_schema.sql`
   2. `20261101000200_auth_helpers.sql`
   3. `20261101000300_order_workflow.sql`
   4. `20261101000400_rls.sql`
   5. `20261101000500_seed_catalog.sql`
   6. `20261101000600_storage.sql`
   7. `20261101000700_admin_audit.sql`
   8. `20261102000100_reports_documents_notifications.sql`

   Файл бүр "Success" гэж гарах ёстой. Алдаа гарвал цааш үргэлжлүүлэлгүй алдааны текстийг надад илгээнэ үү.
   `supabase/local/` хавтсыг **ажиллуулахгүй**. Тэр нь зөвхөн тест орчинд зориулагдсан.
3. **Authentication → URL Configuration**:
   - Site URL: `https://<таны домэйн>` (домэйн байхгүй бол эхлээд Vercel-ийн өгсөн `https://m-advisory.vercel.app` хаяг)
   - Redirect URLs: `https://<таны домэйн>/auth/callback`
4. **Authentication → Providers → Email**: "Confirm email" асаалттай байлгана.
5. **Authentication → Emails → SMTP Settings**: Supabase-ийн үнэгүй имэйл цагт хэдхэн л илгээдэг. Доорх 3-р алхмын Resend-ийн SMTP мэдээллийг энд оруулна (Host `smtp.resend.com`, Port `465`, User `resend`, Password = Resend API key).
6. **Project Settings → API** хэсгээс дараах утгуудыг хуулж авна (4-р алхамд хэрэгтэй):
   - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon` `public` key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role` key → `SUPABASE_SERVICE_ROLE_KEY` (**хэнд ч бүү үзүүл**)
7. **Project Settings → Database → Connection string → Transaction pooler** (port 6543) хаягийг хуулж, `[YOUR-PASSWORD]`-г 1-р алхмын нууц үгээр сольно → `DATABASE_URL`.

## 2. QPay (төлбөр)

1. QPay-тэй **Симкас Пропертиз ХХК**-ийн нэр дээр merchant гэрээ байгуулна (байгаа бол дахин хийх шаардлагагүй). Мөнгө шууд компанийн дансанд орно.
2. QPay-ээс дараах мэдээллийг авна:
   - `QPAY_USERNAME`, `QPAY_PASSWORD` (merchant API нэвтрэх эрх)
   - `QPAY_INVOICE_CODE` (нэхэмжлэхийн код)
   - Эхлээд **sandbox** (туршилтын) эрх авч шалгана: `QPAY_BASE_URL=https://merchant-sandbox.qpay.mn`
   - Туршилт амжилттай болсны дараа жинхэнэ эрх: `QPAY_BASE_URL=https://merchant.qpay.mn`
3. `QPAY_CALLBACK_SECRET`: QPay-ээс авах зүйл биш. Өөрөө 32+ тэмдэгттэй санамсаргүй үг үүсгэнэ (доорх "Санамсаргүй нууц үг үүсгэх" хэсгийг үзнэ үү). Энэ нь QPay-ийн мэдэгдлийг хуурамч хүсэлтээс ялгахад хэрэглэгдэнэ.

QPay эрх ирэх хүртэл сайтыг нээж, захиалга хүлээн авах боломжгүй (төлбөргүй захиалга ажилтанд очдоггүй). Харин бусад бүх алхмыг урьдчилан хийж болно.

## 3. Resend (имэйл мэдэгдэл)

1. https://resend.com дээр бүртгүүлнэ.
2. **Domains → Add domain**: `mproperties.mn` (эсвэл таны домэйн) нэмээд, өгсөн DNS бичлэгүүдийг домэйн бүртгэгчийн самбарт оруулна.
3. **API Keys → Create** → `RESEND_API_KEY`.
4. Илгээгч хаяг: `EMAIL_FROM="M ADVISORY <no-reply@mproperties.mn>"`.

Имэйл тохируулаагүй ч систем ажиллана. Мэдэгдлүүд зөвхөн сайт доторх хонхон дээр харагдана.

## 4. Vercel (сайт байршуулах)

1. https://vercel.com дээр GitHub-аараа нэвтэрнэ → **Add New → Project** → `m-advisory` repo-г сонгоно.
2. Framework: Next.js (автоматаар танина). Бусад тохиргоог өөрчлөхгүй.
3. **Environment Variables** хэсэгт доорх бүгдийг **Production** орчинд оруулна:

| Нэр | Утга |
|---|---|
| `APP_ENV` | `production` |
| `APP_URL` | `https://<таны домэйн>` |
| `DATABASE_URL` | 1.7-р алхмын pooler хаяг |
| `AUTH_PROVIDER` | `supabase` |
| `STORAGE_PROVIDER` | `supabase` |
| `NEXT_PUBLIC_SUPABASE_URL` | 1.6 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 1.6 |
| `SUPABASE_SERVICE_ROLE_KEY` | 1.6 |
| `PAYMENT_PROVIDER` | `qpay` |
| `QPAY_BASE_URL` | 2.2 |
| `QPAY_USERNAME` | 2.2 |
| `QPAY_PASSWORD` | 2.2 |
| `QPAY_INVOICE_CODE` | 2.2 |
| `QPAY_CALLBACK_SECRET` | 2.3, өөрөө үүсгэсэн |
| `CRON_SECRET` | өөрөө үүсгэсэн санамсаргүй үг (32+ тэмдэгт) |
| `RESEND_API_KEY` | 3.3 (заавал биш) |
| `EMAIL_FROM` | 3.4 (заавал биш) |

4. **Deploy** дарна. Тохиргоо дутуу бол сайт асахгүй бөгөөд Vercel-ийн log-д аль утга дутуу байгааг яг нэрээр нь бичнэ.
5. **Settings → Domains**: `advisory.mproperties.mn` гэх мэт домэйн нэмээд, Vercel-ийн өгсөн DNS бичлэгийг оруулна. Дараа нь `APP_URL` болон Supabase-ийн Site URL-г шинэ домэйнээр шинэчилнэ.
6. Шалгах: `https://<домэйн>/api/health` нээхэд `{"ok":true,...}` гарах ёстой.

Өдөр бүр 01:00 UTC-д (Улаанбаатарын 09:00) төлбөрийн тулгалт, имэйл илгээлт, хугацаа нь дууссан файл устгах ажил автоматаар ажиллана (`vercel.json`-д тохируулсан).

## 5. Ерөнхий админ (Super Admin) эрх авах

1. Сайт дээр өөрийн имэйлээр **Бүртгүүлэх** (жишээ нь `togtokhdavaat@gmail.com`), имэйлээ баталгаажуулна.
2. Supabase → **SQL Editor** дээр доорх командыг имэйлээ сольж ажиллуулна:

```sql
insert into public.memberships (user_id, role, branch_id)
select id, 'SUPER_ADMIN', null from auth.users where email = 'togtokhdavaat@gmail.com';
```

3. Сайтаас гараад дахин нэвтэрнэ. Дээд цэсэнд **Ажлын самбар** гарч ирнэ.

Бусад ажилтныг (салбарын админ, зөвлөх, хянагч) нэмэхдээ тэд эхлээд сайтад бүртгүүлсний дараа **Ажлын самбар → Баг** хэсгээс эрх өгнө. SQL дахин хэрэггүй.

## 6. Нээхээс өмнө админ самбараас батлах зүйлс

1. **Ажлын самбар → Тохиргоо → Салбарууд**: "Салбар 1", "Салбар 2" гэсэн түр нэрийг жинхэнэ салбарын нэр, хаягаар сольно.
2. **Ажлын самбар → Үнэ**: бүх үнэ "Санал" төлөвтэй байгаа. Үнэ бүрийг шалгаж, зөв бол **Батлах** (эсвэл **Бүх саналыг батлах**) дарна. Батлагдаагүй үнэтэй үйлчилгээг захиалах боломжгүй.
   - M CHECK: сегмент, үнийн дүнгээр ангилсан 7×3 хүснэгт (₮200,000–₮500,000)
   - M BUY: 2.2% / 1.8% / 1.5% / 1.1% (хамгийн багадаа ₮2,000,000)
3. **Ажлын самбар → Үйлчилгээ**: M VALUE, M INVEST, M REPRESENTATION-ийн тайлбар, нөхцөлийг шалгана. Одоогоор зөвхөн M CHECK онлайнаар захиалагдана. Бусдыг бэлэн болохоор нь идэвхжүүлнэ.
4. **Хуулийн текст**: `/legal/terms` (Үйлчилгээний нөхцөл) болон `/legal/privacy` (Нууцлалын бодлого) хуудсууд **ноорог** төлөвтэй. Хуульчаар хянуулж, баталгаажсан хувилбарыг надад илгээвэл би оруулна. Нууцлалын асуудлаар холбогдох имэйл, утсыг мөн өгнө үү.

---

## 7. Эцсийн шалгалт (нээхийн өмнө 15 минут)

1. Шинэ имэйлээр үйлчлүүлэгч болж бүртгүүлэх → M CHECK захиалга өгөх → QPay sandbox-оор төлөх.
2. Админ эрхээр нэвтэрч захиалгыг зөвлөхөд хуваарилах.
3. Зөвлөхөөр тайлан бөглөж хянуулахаар илгээх → Хянагчаар батлах, нийтлэх.
4. Үйлчлүүлэгчээр PDF тайлангаа татаж авах.
5. Өөр үйлчлүүлэгчийн бүртгэлээр нэвтэрч, эхний үйлчлүүлэгчийн захиалга харагдахгүй байгааг шалгах.

Бүгд амжилттай бол `QPAY_BASE_URL`-г жинхэнэ хаяг руу сольж, жинхэнэ QPay эрхээ оруулаад **Redeploy** хийнэ. Ингээд нээгдлээ.

## Санамсаргүй нууц үг үүсгэх

Компьютерийн terminal дээр:

```
openssl rand -base64 48
```

эсвэл https://1password.com/password-generator (40+ тэмдэгт, тэмдэгт оруулалгүй) ашиглаж болно. `QPAY_CALLBACK_SECRET`, `CRON_SECRET` хоёрт **өөр өөр** утга өгнө.

## Аюулгүй байдлын санамж

- `SUPABASE_SERVICE_ROLE_KEY`, `QPAY_PASSWORD`, өгөгдлийн сангийн нууц үгийг имэйл, чатаар хэнд ч бүү илгээ. Зөвхөн Vercel-ийн тохиргоонд оруулна.
- Supabase, Vercel, GitHub, QPay бүртгэл дээрээ хоёр шатлалт баталгаажуулалт (2FA) асаана.
- Ажилтан гарахад **Ажлын самбар → Баг** хэсгээс эрхийг нь шууд хасна.
